# Установка на Windows

Пошагово, от пустого компьютера до первого записанного чека. Минут двадцать,
из них пятнадцать — ожидание, пока что-то скачивается.

> **Честно с самого начала.** Бот писался и проверялся на macOS. Под Windows
> код подготовлен — место, где он ломался, найдено и исправлено, — но живьём
> на Windows его пока никто не запускал. Если что-то пойдёт не так, дело
> скорее в этом, чем в вас: напишите куратору, что именно вы увидели на
> экране, и это починят.

---

## Шаг 0. Откройте PowerShell

**Пуск → наберите «PowerShell» → Windows PowerShell → Enter.** Откроется синее
или чёрное окно с текстом. Это и есть терминал.

Дальше в инструкции есть строки в рамке. Их нужно скопировать, вставить в
PowerShell и нажать Enter. Вставка в PowerShell — **правая кнопка мыши** или
**Ctrl + V**.

Если терминал вы открыли впервые в жизни — ничего страшного не случится.
Ни одна команда отсюда ничего не удаляет.

---

## Шаг 1. Движок — тот, кто будет читать чеки

Фотографию разбирает Claude Code у вас на компьютере. Проверьте, есть ли он
уже:

```powershell
claude --version
```

**Ответила строка с номером версии** — движок есть, переходите к шагу 2.

**Ответила ошибка** — движка нет, ставим. Сначала Node.js: откройте
[nodejs.org](https://nodejs.org), скачайте версию **LTS** для Windows,
установите обычным двойным щелчком, все галочки оставьте как есть. Потом
**закройте окно PowerShell и откройте заново** — без этого он про новую
программу не узнает. И выполните:

```powershell
npm install -g @anthropic-ai/claude-code
```

Когда установка кончится, наберите `claude` и войдите в свою подписку — Claude
Code откроет браузер и попросит подтвердить вход. Это нужно сделать один раз.

> **Подписка нужна, ключ API — нет.** Больше того: если у вас в переменных
> среды прописан `ANTHROPIC_API_KEY`, бот откажется разбирать чеки и скажет
> почему. С ключом Claude Code уходит с подписки на поминутную оплату, и
> узнают об этом обычно из счёта. Проверить: `echo $env:ANTHROPIC_API_KEY` —
> должно быть пусто.

**Второй движок, Codex,** на Windows ставится так же
(`npm install -g @openai/codex`), но проверен там ещё меньше. Для начала
берите Claude Code.

## Шаг 2. Python

На Windows его, скорее всего, нет — в отличие от мака. Проверьте:

```powershell
python --version
```

**Ответило `Python 3.9` или новее** — годится, идите дальше.

**Открылся магазин приложений или ответила ошибка** — ставим. Откройте
[python.org/downloads](https://www.python.org/downloads/), скачайте свежую
версию, запустите установщик. **Внизу первого экрана установщика есть галочка
«Add python.exe to PATH» — поставьте её.** Без неё терминал Python не найдёт,
и это самая частая ошибка установки на Windows.

Потом закройте PowerShell, откройте заново и проверьте ещё раз.

---

## Шаг 3. Скачайте бота

Проще всего архивом, гит для этого не нужен.

1. Откройте
   [страницу проекта](https://github.com/leogodnik/cheki-bot) и нажмите
   зелёную кнопку **Code → Download ZIP**. Или сразу
   [ссылкой на архив](https://github.com/leogodnik/cheki-bot/archive/refs/heads/main.zip).
2. Найдите скачанный файл в «Загрузках», щёлкните правой кнопкой →
   **Извлечь всё**. Извлеките в «Документы».
3. Внутри получится папка `cheki-bot-main`. Зайдите в неё — если внутри лежит
   ещё одна папка с тем же именем, вам нужна внутренняя, та, в которой лежат
   файлы `bot.py` и `README.md`.
4. Щёлкните по адресной строке проводника, скопируйте путь и перейдите в
   папку в PowerShell:

```powershell
cd "$env:USERPROFILE\Documents\cheki-bot-main"
```

Если путь другой — подставьте свой, в кавычках. Проверить, что вы на месте:
команда `dir` должна показать `bot.py`.

---

## Шаг 4. Поставьте три библиотеки

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

Первая команда заводит для бота отдельный уголок, вторая кладёт туда три
библиотеки. Система при этом не меняется: всё лежит в папке `.venv` внутри
проекта и удаляется вместе с ней.

> Обратите внимание: на Windows путь внутри `.venv` — `Scripts`, а не `bin`.
> В README и в инструкции для macOS написано `bin`; если увидите её где-то
> ещё, мысленно подставляйте `Scripts`.

---

## Шаг 5. Запустите

```powershell
.venv\Scripts\python bot.py
```

В ответ появится примерно это:

```
Телеграм не подключён — работаем через браузер.
Настройка: http://127.0.0.1:8765
Таблица ещё не подключена — открою мастер.
Ctrl+C — выход.
```

Откройте этот адрес в браузере — скопируйте и вставьте в адресную строку.
Дальше всё происходит на странице.

Windows может спросить про доступ в сеть — **отказ ничего не сломает**: бот
слушает только сам себя, наружу ему выходить незачем.

> **Окно PowerShell не закрывайте.** Бот живёт, пока оно открыто. Закроете —
> бот замолчит. Это не поломка, а устройство: бот работает у вас на
> компьютере, а не на чужом сервере.

---

## Шаг 6. Мастер

Обязательных шагов два.

**Движок.** Мастер сам сходил в терминал и показывает, что нашёл, с версиями.

**Таблица**, минут пять.

1. Нажмите «Открыть шаблон». Google предложит сделать **копию** таблицы себе
   на диск — соглашайтесь. Копия ваша, в ней уже есть оба листа, заголовки и
   справочник из шестнадцати статей.
2. В своей копии: **Расширения → Apps Script**.
3. Всё, что там написано, сотрите. Вставьте код с экрана мастера — секретное
   слово в нём уже подставлено, придумывать и запоминать ничего не надо.
4. **Развернуть → Новое развёртывание → Веб-приложение**, доступ — «Все».
   Google попросит разрешения: пройдите их, включая экран «Google не проверил
   это приложение» — приложение ваше собственное, вы его только что и создали.
5. Google выдаст адрес, который кончается на `/exec`. Скопируйте его, вставьте
   в поле мастера и нажмите «Проверить таблицу».

Мастер ответит числом: «прочитано 16 статей». **Число здесь важнее галочки.**

Всё, можно перетаскивать первый чек.

---

## Шаг 7. Телеграм — если хотите

Необязательно. Без телеграма бот полностью рабочий через браузер; телеграм
нужен, чтобы слать чеки с телефона и пускать коллег.

В мастере есть третий, необязательный шаг: открыть в телеграме **@BotFather**,
отправить ему `/newbot`, придумать имя, получить в ответ длинную строку с
двоеточием и вставить её в мастер. Потом написать своему боту любое слово и
впустить себя кнопкой.

## Как пользоваться дальше

Перетащите фотографию чека в окно браузера или напишите трату текстом:
«такси 450 наличными». Ошиблись — следующим сообщением: «не 450, а 480».

**Выключить:** нажмите **Ctrl + C** в PowerShell.

**Включить снова:** откройте PowerShell и выполните две команды. Настройки уже
сохранены, мастер больше не появится.

```powershell
cd "$env:USERPROFILE\Documents\cheki-bot-main"
.venv\Scripts\python bot.py
```

## Если что-то пошло не так

**«Движок не найден», хотя Claude Code стоит.** Сначала простое: терминал
узнаёт про новые программы только при запуске. Закройте окно PowerShell,
откройте заново, запустите бота и нажмите в мастере «Проверить снова».

Не помогло — проверьте прямо в PowerShell: `claude --version`. Если там версия
есть, а мастер движка не видит, это как раз то место, где Windows отличается
от мака. Напишите куратору — правка небольшая, но чинить её надо в коде.

**`python : Имя "python" не распознано`.** Python поставлен без галочки «Add
python.exe to PATH». Запустите установщик Python ещё раз, выберите **Modify**
и включите её. Или переустановите, не забыв галочку.

**Открывается магазин приложений вместо Python.** Это заглушка Microsoft.
Поставьте настоящий Python с python.org (шаг 2), а заглушку можно отключить:
**Параметры → Приложения → Дополнительные параметры приложения → Псевдонимы
выполнения приложения** — выключить оба переключателя со словом Python.

**`npm : Имя "npm" не распознано`.** Node.js не установлен или окно PowerShell
не перезапущено после установки. Закройте и откройте заново.

**Ошибка про «выполнение сценариев отключено в этой системе».** Windows не
даёт запускать скрипты. Выполните один раз:
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, ответьте `Y`.

**Адрес в терминале не 8765, а 8766 или больше.** Так и должно быть: порт был
занят, бот взял следующий свободный. Открывайте тот адрес, который написан.

**«В окружении найден ANTHROPIC_API_KEY».** Уберите его: **Пуск → «переменные
среды» → Изменение переменных среды текущего пользователя**, удалите строку
`ANTHROPIC_API_KEY`, закройте PowerShell, откройте заново.

**Мастер говорит «Это адрес таблицы, а нужен адрес веб-приложения».** Их
действительно два и они похожи. Нужен тот, что кончается на `/exec` и который
Google выдал после «Развернуть» — а не тот, что в адресной строке открытой
таблицы.

**Мастер прочитал 0 статей.** Лист в таблице называется не «Статьи».
Переименуйте и проверьте снова.

**Мастер прочитал 15 статей вместо 16.** Список вставили с ячейки A1, и первая
статья заняла место заголовка. Мастер скажет, какой именно статьи не хватает и
что сделать.

**В терминале вместо русских букв кракозябры.** На работу не влияет, читать
мешает. Выполните один раз перед запуском бота:
`chcp 65001`.
