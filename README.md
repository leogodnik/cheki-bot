# Чеки в таблицу

Бот принимает фотографию чека или сообщение «такси 450 наличными» и дописывает
строку расхода в Google-таблицу. Записанное можно поправить следующим
сообщением: «не 450, а 480». Входов два: рабочее место в браузере и телеграм.
Мозгом служит Claude Code по подписке — ключ API не нужен.

## Запуск

```bash
cd чеки-бот
/Library/Frameworks/Python.framework/Versions/3.13/bin/python3 -m venv .venv
.venv/bin/pip install requests python-dotenv flask

cp .env.example .env            # токен бота, адрес Apps Script, секрет
chmod 600 .env
cp settings.example.json settings.json
```

Прежде чем запускать бота, заведите таблицу и веб-приложение Apps Script по
`sheet-setup.md` — без опубликованного веб-приложения бот не увидит
справочник статей.

```bash
.venv/bin/python bot.py
```

В терминале появится адрес вида `http://127.0.0.1:8765` — откройте его.
Перетащите фотографию чека в окно или напишите трату текстом.

Телеграм необязателен: с пустым `BOT_TOKEN` бот работает через браузер.
Страница слушает только `127.0.0.1` — снаружи её не видно, пароля у неё нет.

Бот работает, пока открыт терминал. Закрыли ноутбук — бот молчит, сообщения
копятся в телеграме и разберутся при следующем запуске.

## Как впустить себя

Напишите своему боту. В терминале появится готовая строка — вставьте её в
`settings.json`, в список `allowed`, и напишите ещё раз. Перезапускать не надо.

## Файлы

| Файл | Что |
|---|---|
| `prompt.md` | мозг агента: что искать в чеке и когда не угадывать |
| `schema.json` | поля ответа, ими же ответ и проверяется |
| `agent.py` | шов: зовёт движок и проверяет форму ответа |
| `engines/claude_code.py` | вызов Claude Code |
| `engines/codex.py` | вызов Codex CLI по подписке ChatGPT |
| `checks.py` | проверки без модели — главное место проекта |
| `intake.py` | единый приём: один разбор на телеграм и браузер |
| `bot.py` | телеграм и потоки: приём, очередь, разбор |
| `web.py` | рабочее место: страница и три маршрута |
| `feed.py` | лента: журнал событий в памяти |
| `static/app.js` | клиент: опрос ленты, отрисовка, перетаскивание |
| `sheet.py` / `sheet.gs` | мост к Google-таблице |
| `config.py` | `.env` и `settings.json` |
| `state.py` | служебная память; удалять только когда очередь пуста |

## Проверки

```bash
.venv/bin/python tools/selfcheck.py                    # чистые функции
.venv/bin/python agent.py тестовые-чеки/01-чёткий.jpg  # агент живьём
.venv/bin/python agent.py тестовые-чеки/01-чёткий.jpg codex  # тот же чек вторым движком
.venv/bin/python sheet.py                              # связь с таблицей
.venv/bin/python sheet.py правка                       # правка строки и отказ по сверке
```

`sheet.py` требует настроенную таблицу и адрес в `.env` (см. `sheet-setup.md`)
— без них он падает сырым английским traceback (`MissingSchema`), а не
понятной ошибкой.

Живьём проверяется по разделу «Как проверяем» в
`docs/superpowers/specs/2026-08-23-чеки-в-таблицу-design.md`.

## Чего бот не делает

Не разбирает голосовые: расшифровки в Bot API нет, а локальная ломает
экономику проекта. Не работает на сервере круглосуточно и не считает суммы за
месяц — для этого есть таблица.

Правит только **последнюю** запись и только в своём канале: «не 450, а 480»
меняет ту строку, которую бот записал вам последней. Произвольную строку он не
правит и чужую не трогает — если последней записал кто-то другой, бот честно
откажется и скажет, чья это строка. Правьте такое в таблице руками.

Не управляет белым списком из браузера и не ставится мастером: `.env` и
`settings.json` заполняются руками.
