# Чеки в таблицу

Бот принимает фотографию чека или сообщение «такси 450 наличными» и дописывает
строку расхода в Google-таблицу. Записанное можно поправить следующим
сообщением: «не 450, а 480». Входов два: рабочее место в браузере и телеграм.
Мозгом служит Claude Code или Codex по подписке — ключ API не нужен.

## Ставим первый раз

Пошагово, с картинками словами и разбором частых ошибок:

- **[Установка на macOS](УСТАНОВКА-macOS.md)** — проверено живьём
- **[Установка на Windows](УСТАНОВКА-Windows.md)** — код подготовлен, живьём не проверялось

Ниже — то же самое коротко, для тех, кто с терминалом на «ты».

## Что нужно заранее

**Движок** — Claude Code или Codex в терминале, любой один, по подписке. Не
стоит ни того, ни другого — мастер это увидит и покажет команду установки.

**Python 3** и **аккаунт Google**. Больше ничего: ни Google Cloud, ни
сервисного аккаунта, ни файла с ключами — мост к таблице существует затем,
чтобы их не заводить.

Если в окружении задан `ANTHROPIC_API_KEY`, бот поднимется, но чеки разбирать
откажется и скажет почему: с ключом Claude Code уходит с подписки на поминутную
оплату, и узнают об этом обычно из счёта.

## Запуск

```bash
git clone https://github.com/leogodnik/cheki-bot.git
cd cheki-bot
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python bot.py
```

В терминале появится адрес вида `http://127.0.0.1:8765` — откройте его.

Копировать `.env.example` и `settings.example.json` руками не нужно: `.env` бот
заведёт сам, а секрет для таблицы придумает и впишет в оба места, где тот
нужен. Образцы лежат в репозитории затем, чтобы было видно, из каких строк
файлы состоят.

Команды здесь для macOS и Linux. На Windows путь до питона в окружении другой
(`.venv\Scripts\python`) — см. [УСТАНОВКА-Windows.md](УСТАНОВКА-Windows.md).
Живьём на Windows бот не запускался; код к нему подготовлен, но это не то же
самое, что проверен.

Бот работает, пока открыт терминал. Закрыли ноутбук — бот молчит, сообщения
копятся в телеграме и разберутся при следующем запуске. Страница слушает только
`127.0.0.1` — снаружи её не видно, пароля у неё нет.

## Мастер установки

Пока таблица не подключена, по тому же адресу открывается мастер. Обязательных
шагов два.

**Движок.** Мастер сходил в терминал и показывает, что нашёл, с версиями.
Установлены оба — берите любой, переключается потом в один щелчок.

**Таблица**, минут пять. Кнопка открывает готовый шаблон; ссылка кончается на
`/copy`, поэтому Google не открывает чужую таблицу, а сразу предлагает сделать
вам вашу собственную. В копии уже есть оба листа с точными именами,
одиннадцать заголовков в нужном порядке и справочник из шестнадцати статей.
Дальше в своей копии: **Расширения → Apps Script**, стереть всё, вставить код
с экрана — секрет в нём уже подставлен, — потом **Развернуть → Новое
развёртывание → Веб-приложение**, доступ «Все». Google выдаст адрес, который
кончается на `/exec`; его нужно вставить в поле и нажать «Проверить таблицу».

Отвечает мастер не галочкой, а числом прочитанных статей, и число здесь
важнее галочки. Ноль означает, что лист называется не «Статьи». Пятнадцать
вместо шестнадцати — что список вставили с ячейки A1 и первая статья заняла
место заголовка; про этот случай мастер говорит отдельно, потому что не хватать
будет всегда «Продуктов», самой ходовой статьи, и приёмка после этого выглядит
провалом разбора, хотя разбор верен.

Телеграм — необязательный третий шаг: токен от @BotFather, потом написать
своему боту любое слово и впустить себя кнопкой. С пустым `BOT_TOKEN` бот
работает через браузер.

Что мастер делает за кулисами, что отвечает мост и как собрать ту же таблицу
руками — в `sheet-setup.md`.

## Рабочее место

Перетащите фотографию чека в окно или напишите трату текстом. Ошиблись —
следующим сообщением: «не 450, а 480».

В сайдбаре, кроме самой ленты, четыре пункта. **Таблица** — открывает её в
новой вкладке и показывает число статей в справочнике. **Доступ** — белый список телеграма: кто написал боту, тот
появляется в «стучались», и его впускают кнопкой. **Телеграм** — подключить,
заменить бота или отключить. **Движок** — переключить; перезапускать не надо,
следующий чек разберётся уже новым.

## Проверки

```bash
.venv/bin/python tools/selfcheck.py                    # чистые функции
.venv/bin/python agent.py тестовые-чеки/01-чёткий.jpg  # агент живьём
.venv/bin/python agent.py тестовые-чеки/01-чёткий.jpg codex  # тот же чек вторым движком
.venv/bin/python sheet.py                              # связь с таблицей
.venv/bin/python sheet.py правка                       # правка строки и отказ по сверке
```

`sheet.py` требует пройденного мастера: без адреса и секрета в `.env` он падает
сырым английским traceback (`MissingSchema`), а не понятной ошибкой.

Живьём проверяется по разделу «Как проверяем» в
`docs/superpowers/specs/2026-08-23-чеки-в-таблицу-design.md`.

## Чего бот не делает

Не разбирает голосовые: расшифровки в Bot API нет, а локальная ломает
экономику проекта. Не работает на сервере круглосуточно и не считает суммы за
месяц — для этого есть таблица.

Правит только **последнюю** запись и только в своём канале: «не 450, а 480»
меняет ту строку, которую бот записал вам последней. Произвольную строку он не
правит и чужую не трогает — если последней записал кто-то другой, бот честно
откажется и скажет, чья это строка. Правьте такое в таблице руками.
