# Чеки в таблицу

Телеграм-бот принимает фотографию чека или сообщение «такси 450 наличными» и
дописывает строку расхода в Google-таблицу. Мозгом служит Claude Code по
подписке — ключ API не нужен.

## Запуск

```bash
cd чеки-бот
/Library/Frameworks/Python.framework/Versions/3.13/bin/python3 -m venv .venv
.venv/bin/pip install requests python-dotenv

cp .env.example .env            # токен бота, адрес Apps Script, секрет
chmod 600 .env
cp settings.example.json settings.json

.venv/bin/python bot.py
```

Бот работает, пока открыт терминал. Закрыли ноутбук — бот молчит, сообщения
копятся в телеграме и разберутся при следующем запуске.

## Как впустить себя

Напишите своему боту. В терминале появится готовая строка — вставьте её в
`settings.json`, в список `allowed`, и напишите ещё раз. Перезапускать не надо.

## Файлы

| Файл | Что |
|---|---|
| `prompt.md` | мозг агента: что искать в чеке и когда не угадывать |
| `schema.json` | поля ответа, ими же ответ и проверяется |
| `agent.py` | шов: зовёт движок и проверяет форму ответа |
| `engines/claude_code.py` | вызов Claude Code |
| `checks.py` | проверки без модели — главное место проекта |
| `bot.py` | телеграм: приём, скачивание, запись, ответ |
| `sheet.py` / `sheet.gs` | мост к Google-таблице |
| `config.py` | `.env` и `settings.json` |
| `state.py` | служебная память; этот файл можно удалять |

## Проверки

```bash
.venv/bin/python tools/selfcheck.py                    # чистые функции
.venv/bin/python agent.py тестовые-чеки/01-чёткий.jpg  # агент живьём
.venv/bin/python sheet.py                              # связь с таблицей
```

Живьём проверяется по разделу «Как проверяем» в
`docs/superpowers/specs/2026-08-23-чеки-в-таблицу-design.md`.

## Чего бот не делает

Не разбирает голосовые: расшифровки в Bot API нет, а локальная ломает
экономику проекта. Не работает на сервере круглосуточно, не редактирует уже
записанные строки, не считает суммы за месяц — для этого есть таблица.

Телеграм здесь — единственный вход, но не навсегда: в следующем срезе рядом
появится приём чеков в браузере (спека
`docs/superpowers/specs/2026-09-02-рабочее-место-design.md`), и телеграм
станет одним из двух способов, а не обязательным.
