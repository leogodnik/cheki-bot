# Установка на macOS

Пошагово, от пустого компьютера до первого записанного чека. Минут пятнадцать,
из них десять — ожидание, пока что-то скачивается.

Всё, что здесь есть, проверено на macOS живьём.

---

## Шаг 0. Откройте Терминал

Он уже стоит: **Cmd + Пробел**, наберите «Терминал», нажмите Enter.

Дальше в инструкции есть строки в рамке. Их нужно скопировать, вставить в
Терминал и нажать Enter. Вставка в Терминале — обычная, **Cmd + V**.

Если Терминал вы открыли впервые в жизни — ничего страшного не случится.
Ни одна команда отсюда ничего не удаляет.

---

## Шаг 1. Движок — тот, кто будет читать чеки

Фотографию разбирает Claude Code или Codex у вас на компьютере. Нужен **любой
один**. Проверьте, есть ли он уже:

```bash
claude --version
```

**Ответила строка с номером версии** — движок есть, переходите к шагу 2.

**Ответило `command not found`** — движка нет, ставим. Сначала Node.js: откройте
[nodejs.org](https://nodejs.org), скачайте версию LTS, установите обычным
двойным щелчком. Потом закройте Терминал, откройте заново и выполните:

```bash
npm install -g @anthropic-ai/claude-code
```

Когда установка кончится, наберите `claude` и войдите в свою подписку — Claude
Code откроет браузер и попросит подтвердить вход. Это нужно сделать один раз.

> **Подписка нужна, ключ API — нет.** Больше того: если у вас в окружении
> прописан `ANTHROPIC_API_KEY`, бот откажется разбирать чеки и скажет почему.
> С ключом Claude Code уходит с подписки на поминутную оплату, и узнают об этом
> обычно из счёта. Проверить: `echo $ANTHROPIC_API_KEY` — должно быть пусто.

---

## Шаг 2. Python

На маке он уже стоит. Проверьте:

```bash
python3 --version
```

Ответило `Python 3.9` или новее — годится, идите дальше. Бот проверен и на
3.9, и на 3.13.

Если система вместо ответа предложит установить «инструменты разработчика
командной строки» — согласитесь и дождитесь конца установки. Это Apple, а не
наш бот.

---

## Шаг 3. Скачайте бота

**Если у вас есть `git`** (проверить: `git --version`):

```bash
cd ~/Documents
git clone https://github.com/leogodnik/cheki-bot.git
cd cheki-bot
```

**Если гита нет** — не ставьте его ради этого. Скачайте
[архивом](https://github.com/leogodnik/cheki-bot/archive/refs/heads/main.zip),
распакуйте двойным щелчком, перетащите получившуюся папку в «Документы».
Потом наберите в Терминале `cd ` (со пробелом в конце) и перетащите папку
прямо в окно Терминала — путь подставится сам. Enter.

---

## Шаг 4. Поставьте три библиотеки

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

Первая команда заводит для бота отдельный уголок, вторая кладёт туда три
библиотеки. Система при этом не меняется: всё лежит в папке `.venv` внутри
проекта, и удаляется вместе с ней.

---

## Шаг 5. Запустите

```bash
.venv/bin/python bot.py
```

В ответ появится примерно это:

```
Телеграм не подключён — работаем через браузер.
Настройка: http://127.0.0.1:8765
Таблица ещё не подключена — открою мастер.
Ctrl+C — выход.
```

Откройте адрес в браузере — **Cmd + щелчок** по нему прямо в Терминале.
Дальше всё происходит на странице.

> **Терминал не закрывайте.** Бот живёт, пока открыто это окно. Закроете —
> бот замолчит. Это не поломка, а устройство: бот работает у вас на
> компьютере, а не на чужом сервере.

---

## Шаг 6. Мастер

Обязательных шагов два.

**Движок.** Мастер сам сходил в терминал и показывает, что нашёл, с версиями.
Стоят оба — берите любой, переключить можно потом в один щелчок.

**Таблица**, минут пять.

1. Нажмите «Открыть шаблон». Google предложит сделать **копию** таблицы себе на
   диск — соглашайтесь. Копия ваша, в ней уже есть оба листа, заголовки и
   справочник из шестнадцати статей.
2. В своей копии: **Расширения → Apps Script**.
3. Всё, что там написано, сотрите. Вставьте код с экрана мастера — секретное
   слово в нём уже подставлено, придумывать и запоминать ничего не надо.
4. **Развернуть → Новое развёртывание → Веб-приложение**, доступ — «Все».
   Google попросит разрешения: пройдите их, включая экран «Google не проверил
   это приложение» — приложение ваше собственное, вы его только что и создали.
5. Google выдаст адрес, который кончается на `/exec`. Скопируйте его, вставьте
   в поле мастера и нажмите «Проверить таблицу».

Мастер ответит числом: «прочитано 16 статей». **Число здесь важнее галочки.**

Всё, можно перетаскивать первый чек.

---

## Шаг 7. Телеграм — если хотите

Необязательно. Без телеграма бот полностью рабочий через браузер; телеграм
нужен, чтобы слать чеки с телефона и пускать коллег.

В мастере есть третий, необязательный шаг: открыть в телеграме **@BotFather**,
отправить ему `/newbot`, придумать имя, получить в ответ длинную строку с
двоеточием и вставить её в мастер. Потом написать своему боту любое слово и
впустить себя кнопкой.

## Как пользоваться дальше

Перетащите фотографию чека в окно браузера или напишите трату текстом:
«такси 450 наличными». Ошиблись — следующим сообщением: «не 450, а 480».

**Выключить:** нажмите **Ctrl + C** в Терминале.

**Включить снова:** откройте Терминал и выполните две команды — перейти в папку
и запустить. Настройки уже сохранены, мастер больше не появится.

```bash
cd ~/Documents/cheki-bot
.venv/bin/python bot.py
```

## Если что-то пошло не так

**«Движок не найден», хотя Claude Code стоит.** Терминал узнаёт про новые
программы только при запуске. Закройте окно Терминала, откройте заново и
нажмите в мастере «Проверить снова».

**«В окружении найден ANTHROPIC_API_KEY».** Уберите строку с ним из `~/.zshrc`,
закройте Терминал, откройте заново, запустите бота ещё раз.

**Адрес в Терминале не 8765, а 8766 или больше.** Так и должно быть: порт был
занят, бот взял следующий свободный. Открывайте тот адрес, который написан.

**Мастер говорит «Это адрес таблицы, а нужен адрес веб-приложения».** Их
действительно два и они похожи. Нужен тот, что кончается на `/exec` и который
Google выдал после «Развернуть» — а не тот, что в адресной строке открытой
таблицы. Первый мастер, кстати, тоже запомнил — он пойдёт на кнопку «Таблица».

**Мастер прочитал 0 статей.** Лист в таблице называется не «Статьи».
Переименуйте и проверьте снова.

**Мастер прочитал 15 статей вместо 16.** Список вставили с ячейки A1, и первая
статья заняла место заголовка. Мастер скажет, какой именно статьи не хватает и
что сделать.

**`command not found: python3`.** Согласитесь на предложение установить
инструменты разработчика (шаг 2) и повторите.
