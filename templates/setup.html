Чеки
Шаг 1 из 2

Кто будет читать чеки

Фотографию разбирает агент у вас на компьютере — тот же, в котором вы работаете. Мы уже сходили в терминал и посмотрели, что установлено.

Промпт, схема и все проверки у движков общие: страховка от ошибок модели не может зависеть от того, чья модель ошиблась. Различаются команда, способ передать картинку и модель. Установлены оба — берите любой, переключить можно потом в один щелчок.

Шаг 1 из 2

Движок не найден

Ни claude, ни codex в терминале не отвечают. Без движка бот бессмыслен: читать чек будет нечем.

Установить Claude Code 
npm install -g @anthropic-ai/claude-code
…или Codex 
npm install -g @openai/codex

Выполните любую из двух команд в терминале, дождитесь конца установки и нажмите «Проверить снова». Хватит одного движка — второй ставить незачем. Если npm тоже не найден — сначала поставьте Node.js с nodejs.org.

Шаг 2 из 2

Google-таблица

Минут пять, и это последнее, что нужно сделать руками. Таблица готова: два листа, «Расходы» и «Статьи», с нужными заголовками. Вам остаётся сделать копию и вставить в неё кусок кода.

Шаблон

Таблица с обоими листами Открыть шаблон

В открывшейся таблице: Файл → Создать копию. Копия ваша, менять в ней можно всё.

Код для таблицы

В своей копии: Расширения → Apps Script. Всё, что там есть, удалите и вставьте это. Секретное слово уже вписано — придумывать и запоминать ничего не надо.

Apps Script 
const SECRET = 'k7m2-qp94-xr3v';

function doPost(e) {
  const d = JSON.parse(e.postData.contents);
  if (d.secret !== SECRET) return reply({ok: false, error: 'нет доступа'});

  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('Расходы');
  if (!sheet) return reply({ok: false, error: 'в таблице нет листа «Расходы»'});

  sheet.appendRow([
    d.date, d.amount, d.currency, d.merchant, d.category,
    d.payment, d.source, d.who, d.status, d.file, new Date()
  ]);
  return reply({ok: true, row: sheet.getLastRow()});
}

function doGet(e) {
  if (e.parameter.secret !== SECRET) return reply({ok: false, error: 'нет доступа'});

  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('Статьи');
  if (!sheet) return reply({ok: false, error: 'в таблице нет листа «Статьи»'});

  const last = sheet.getLastRow();
  const rows = last < 2 ? [] : sheet.getRange(2, 1, last - 1, 1).getValues();
  return reply({ok: true, categories: rows.map(r => String(r[0]).trim()).filter(Boolean)});
}

function reply(o) {
  return ContentService.createTextOutput(JSON.stringify(o))
    .setMimeType(ContentService.MimeType.JSON);
}

Необязательно

Телеграм нужен, чтобы слать чеки с телефона и пускать коллег. Без него рабочее место работает полностью — подключить можно когда угодно, из раздела «Телеграм».

Открыть рабочее место
Необязательно · Телеграм

Токен бота

Откройте в телеграме @BotFather — это официальный бот, который заводит всех остальных. Отправьте ему /newbot и придумайте имя. В ответ придёт длинная строка с двоеточием посередине: это и есть токен.

Токен принят. Бота зовут @leo_cheki_bot — это он?

Строка никуда, кроме вашего компьютера, не уходит: рабочее место живёт на 127.0.0.1 и пишет токен в файл .env рядом с ботом.

Напишите своему боту
